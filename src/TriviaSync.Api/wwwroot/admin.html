Formatting guide

Start each question with Q1:. List choices as A), B)… and mark the right one with *, or use [x] / [ ] for true/false. Time: and Points: are optional (defaults: 20s, 1000).

Q1: Which planet is closest to the sun?
A) Venus
B) Mercury *
C) Mars
Time: 15s

Q2: The Pacific is the largest ocean.
[x] True
[ ] False
